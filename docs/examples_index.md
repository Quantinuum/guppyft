# Guppy FT examples

Here are some example notebooks which demonstrate some of the key features in Guppy FT.

The examples are [marimo](https://marimo.io/) notebooks stored as Python files in
the `examples/` directory. Open one from the repository root with:

```sh
uv run --group examples marimo edit examples/steane_encoding.py
```

Run a notebook as a script with `uv run --group examples python examples/steane_encoding.py`.
