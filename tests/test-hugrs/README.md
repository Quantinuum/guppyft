The HUGRs in this directory with names beginning `tests.integration` were
generated by running `just export-integration-tests` in the `guppylang` repo (at
commit `efcf084b7ae35d9be4779c17d808d8cb8d15b588`), and then selecting only
those that can be directly encoded with Steane, i.e.:

- are not `Module`-rooted;
- have an entrypoint signature of `[] -> []`;
- have only supported quantum operations;
- are not `tests.integration.test_array-test_array_reverse_linear.hugr`, which
  has a [known issue](https://github.com/quantinuum-dev/guppyft/issues/225).
